# Dataset

Download an e-commerce CSV dataset with 1000+ rows. Good options:

1. **Kaggle — Brazilian E-Commerce (Olist)**
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
   Use `olist_orders_dataset.csv` + `olist_order_items_dataset.csv`

2. **Kaggle — Online Retail II**
   https://www.kaggle.com/datasets/lakshmi25npathi/online-retail-dataset

3. **Generate synthetic data** using Faker or similar

Place the CSV file(s) in this directory before ingesting into Tinybird.
